# Market Recce

## Purpose

Market Recce is a personal research project for product discovery and small-business planning.

The goal is to help me investigate potential product niches by organising relevant product information, comparing listing characteristics and advertised prices, and identifying questions for further market research.

## Intended use

The initial version is intended for my own research and decision-making. It is not currently a public service and is not being developed on behalf of an existing third-party application.

Potential research dimensions include:

- Product categories and niche characteristics
- Advertised listing prices
- Listing descriptions and product attributes
- Publicly displayed review information, where access is permitted
- Comparisons between potential product opportunities

## Data access and compliance

Any integration with Etsy will depend on approval and the permissions granted by Etsy.

The project will use only data sources and access methods authorised for the intended purpose. It will not use unauthorised scraping or attempt to bypass Etsy's access controls.

The scope of Etsy data collection and analysis will be determined by Etsy's applicable API Terms of Use and any additional written authorisation required.

## Development status

This project is at the planning stage. The intended workflow, data sources and technical implementation have not yet been finalised.
